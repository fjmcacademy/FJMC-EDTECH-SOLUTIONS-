YOURSTUDIO — SOFTWARE PORTFOLIO WEBSITE

FILES
- index.html      Main portfolio page with software cards
- software.html   Individual product detail page
- style.css       Responsive professional styling
- app.js          Product information and page behaviour

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in a browser.
3. Click any product card. Its details open in a new browser tab.

HOW TO ADD OR EDIT SOFTWARE
Open app.js and edit the `products` array near the top.
Each product has:
- id: unique short identifier (use lowercase letters and hyphens)
- name, category, icon
- tagline and description
- features: list of key features
- steps: how the software works
- platform, status, developer
- url: actual application URL (replace #)

To add another app, copy one product object, paste it inside the array, add a comma between objects, and edit its details.
